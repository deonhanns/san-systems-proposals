San Systems - proposal for Melted Workx

One record. Every role. Nothing manual twice.

An event operations platform that gives your team back the time currently lost to spreadsheets, so it can go toward the brand and client work Melted Workx is built to deliver.

Draft v0.1 Prepared for Naidene Cary 31 August 2026

The problem

Right now, one spreadsheet is doing the work of six systems: guest intake, ops tracking, accreditation, session logistics, shuttle coordination, and guest communication, for delegates across multiple countries and languages, with no single source of truth.

What we found in the current data: duplicate delegate records with conflicting details already exist in the live conference sheet. Passport images sit as unmanaged Drive links. Accessibility and dietary needs live in unstructured free text across three languages. WhatsApp numbers are collected for a day-before logistics message that today has no automated path.

Every downstream need, the dashboard, the accreditation list, the shuttle manifest, is hand-derived from the same raw sheet, every time, by a person. That person's time is the scarce resource that should be going to brand and client relationships instead.

The architecture

One data core, exposed as role-scoped views. No duplicate entry, no re-keying between spreadsheets, and adding a new role later means a new view, not a new system.

Naidene's dashboard doesn't need to be checked, it pushes only when something needs attention: a conflicting record, an incomplete profile, an unfilled shuttle seat. Everything else, it stays quiet.

Notifications

Change-triggered, not manually sent, split by purpose rather than preference:

  • SMS, the default for time-critical logistics (shuttle pickup, gate changes, check-in reminders). Works without an app, data connectivity, or opt-in friction, which matters given the delegate base spans Mozambique, Zimbabwe, Ethiopia, Botswana and beyond.
  • WhatsApp, rich content: QR codes, agenda links, documents.
  • Escalation by time-to-event, channel selection shifts to SMS automatically as an event approaches.
  • Correction loop, a guest reply ("wrong flight") auto-flags their record for review, using the same channel that sent the reminder.
Worth sizing before we quote a number: cross-border SMS pricing varies significantly by country, and some African markets require pre-registered sender IDs ahead of the next event. We'll pull the real country-code distribution from your data to size this line item.

Consent & data handling

Passport images and health or accessibility data are collected across multiple jurisdictions. The intake wizard carries explicit consent language for automated messaging, rather than treating consent as implied by a submitted WhatsApp number.

Crew management

Naidene assembles a different team per event, that gets the same treatment as delegate data, not a bolted-on afterthought.

  • Crew records mirror the delegate architecture: one core, role-scoped views, applied to a second population.
  • Time-bound access, a crew member's permissions activate on assignment and auto-expire when the event closes. No manual revocation step, no standing access risk from past freelance staff.
  • Same device, one more job, the accreditation tablet already scanning guests also handles crew check-in on event day.
