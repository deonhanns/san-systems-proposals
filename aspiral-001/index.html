02 — What Is This, Really?

Not a tool.
An operating system
for Aspiral.

The Aspiral OS is a custom-built AI infrastructure that sits underneath Roland's practice — invisible to clients, indispensable to the business. It doesn't replace how Roland coaches. It replaces everything that gets in the way of it.

The technical stack — plain English
  • WhatsApp Business API — the single interface Roland and his clients already use. No new apps, no logins, no friction.
  • n8n automation engine — the invisible orchestration layer. Connects everything. Runs 24/7 without anyone touching it.
  • Claude AI (Anthropic) — the intelligence that reads, drafts, personalises, and decides. This is what makes messages sound like Roland, not like a robot.
  • Google Calendar — the scheduling backbone. Free, mobile-native, works with every client's calendar already.
  • Google Drive — secure, searchable client document storage. Accessible from Roland's phone, anywhere, instantly.
What the AI handles
  • ⚙ All scheduling back-and-forth with clients
  • ⚙ Cancellation handling and policy enforcement
  • ⚙ Session reminders to clients (24hr and 1hr before)
  • ⚙ Re-engagement messages to clients who've gone quiet
  • ⚙ Pre-session client brief (delivered to Roland's phone)
  • ⚙ Post-session outcome summary to client
  • ⚙ Between-session accountability check-ins
What Roland keeps
  • ♦ Every coaching session — 100% Roland
  • ♦ Every relationship — human, warm, trusted
  • ♦ His voice in every message (AI drafts; Roland's tone)
  • ♦ Full control — approve any message before it sends
  • ♦ His methodology and assessment IP
  • ♦ The breakthroughs — the moments only he can create
